# ファイルを検索する

タイトルと、HTML ファイルと Markdown ファイルの本文を検索できます。静的サイト内の HTML・Markdown ページの本文も対象です。検索対象は現在の公開版です。PDF と動画はタイトルと説明文が対象で、PDF の本文や動画の音声は含みません。

**⌘K / Ctrl+K** で検索を開きます。文字を入力する欄の外では **/** でも開けます。IME で文字を変換している間は、ショートカットや Enter による検索操作は行われません。

検索語を入力し、**所有者**、**プロジェクト**、**期間**で絞り込みます。期間は、ファイルの活動を基準にする「**更新日**」か、自分の直近の閲覧を基準にする「**自分が最後に見た日**」を選び、日付の範囲を指定します。

候補を選ばずに **Enter** を押すと、検索結果ページを開きます。矢印キーで候補を選んだ後の Enter は、その候補を実行します。

- 所有者やプロジェクトの候補は、検索条件に追加します。
- ファイルの候補は、そのファイルを開きます。
- 検索履歴の候補は、その検索をもう一度実行します。
- すべての結果を表示する候補は、検索結果ページを開きます。

入力中の候補は検索結果より対象が狭いため、候補に出なくても検索結果に見つかる場合があります。

管理者権限だけで開けるファイルは、検索には出ません。検索対象は、アクセスが有効な自分のファイル、直接共有されたファイル、自分がワークスペースやプロジェクトの共有対象に含まれるファイルです。リンク共有だけでアクセスできるファイルは、ログインして一度開いたものに限り、リンクが有効でワークスペースのリンク共有が許可されている間だけ見つかります。アーカイブ済みプロジェクト内のファイルは、初期状態では検索対象から除かれます。

エージェントやスクリプトからは、MCP の `list_artifacts` と CLI の `artifacts list --q` でこれらのファイルを検索できます。制限付きエージェントやボットの資格情報では、読み取れるプロジェクトの範囲に絞られます。絞り込みの指定やエラー時の対応は [CLI リファレンス](/ja/guides/cli#recovery) にあります。

## 1日の検索回数の上限

全文検索は、すべてのプランで認証された利用者1人につき UTC の1日あたり1,000回まで利用できます。Web画面・API・MCP・CLIで回数を共有します。入力した語の候補検索、条件だけの検索、次の結果ページや同じタイトルのファイルの取得も数えます。空欄時の検索履歴とタイトルだけのファイル一覧は対象外です。受け付けた検索は、結果が0件でも、その後に失敗しても1回と数えます。

上限に達すると、検索を再開できる日時とタイムゾーンを表示します。それまでお待ちください。検索語の変更や直後の再試行では再開できません。検索語と条件は保持されます。
