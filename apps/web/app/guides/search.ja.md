# ファイルを検索する

ファイルのタイトルだけでなく、HTML と Markdown の本文も検索できます。静的サイトに含まれる HTML・Markdown ページの本文も対象です。検索されるのは現在の公開版で、PDF と動画についてはタイトルと説明文だけが対象になります（PDF の本文や動画の音声は含まれません）。

**⌘K / Ctrl+K** で検索を開けます。入力欄にカーソルがない状態なら **/** でも開けます。日本語入力（IME）で変換している最中は、ショートカットや Enter による検索は動きません。

検索語を入れたら、**所有者**、**プロジェクト**、**期間**で絞り込めます。期間の基準は、ファイルの更新をもとにした「**更新日**」か、自分が最後に開いた日時をもとにした「**自分が最後に見た日**」から選び、日付の範囲を指定します。

候補を選ばずに **Enter** を押すと検索結果ページが開きます。矢印キーで候補を選んでから Enter を押すと、その候補に応じた操作が動きます。

- 所有者やプロジェクトの候補: 検索条件に加えます。
- ファイルの候補: そのファイルを直接開きます。
- 検索履歴の候補: 同じ検索をもう一度実行します。
- すべての結果を表示する候補: 検索結果ページを開きます。

入力中に出る候補は検索結果ページより対象が狭いため、候補に出なくても検索結果ページで見つかることがあります。

検索の対象になるのは、自分がアクセスできるファイルに限られます。具体的には、自分のファイル、個別に共有されたファイル、自分がワークスペースやプロジェクトの共有範囲に含まれるファイルです。管理者権限だけで見られるファイルは検索には出ません。リンク共有だけで閲覧できるファイルは、ログインした状態で一度開いたものに限り、リンクが有効でワークスペースのリンク共有が許されているあいだだけヒットします。アーカイブ済みプロジェクトのファイルは、初期状態では対象外です。

エージェントやスクリプトからは、MCP の `list_artifacts` や CLI の `artifacts list --q` で検索できます。権限を絞ったエージェントやボットでは、読み取れるプロジェクトの範囲だけが対象になります。絞り込みの指定方法やエラー時の対処は [CLI リファレンス](/ja/guides/cli#recovery) にまとめています。

## 1 日の検索回数の上限

全文検索は、どのプランでもログイン済みの利用者 1 人につき UTC の 1 日あたり 1,000 回まで使えます。この回数は Web・API・MCP・CLI のすべてで合算されます。入力中の候補検索、条件だけの検索、次のページの読み込み、同じタイトルのファイル一覧の取得も 1 回と数えます。空欄のまま開く検索履歴と、タイトルだけの一覧取得は回数に含めません。受け付けた検索は、結果が 0 件でも、途中で失敗しても 1 回に数えます。

上限に達すると、次に検索できるようになる日時とタイムゾーンが表示されます。その時刻までお待ちください。検索語を変えたりすぐやり直したりしても解除されませんが、入力していた検索語と条件はそのまま残ります。
