新しい CLI リファレンスを公開しました。ターミナルからファイルを共有、更新、読み取り、コメント、整理する方法に加え、JSON 出力、設定、投稿先、エラー時の復旧手順もまとめています。利用者とエージェントの双方が、必要なコマンドをすぐ見つけられます。

あわせて、移動中にモバイルの開発環境とエージェントで作った設計文書を PC へ安全に引き継ぐ使い方も案内しています。手元の CLI 環境で `home_audience` を `private` に設定しておけば、毎回共有範囲を指定しなくても、作業中の文書を意図せず社内全員へ共有してしまう心配がありません。

投稿先を指定しない `share` は home に投稿されます。個人の安全な既定値には user スコープを使い、`--scope effective` で実際に適用される値を確認できます。`--scope repository` は参加者全員が合意した方針に限って使ってください。
