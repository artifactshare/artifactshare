The source code for Artifact Share is now available on [GitHub](https://github.com/artifactshare/artifactshare). You may study and modify the code and self-host it for your organization.

The repository is source-available, not OSI-approved open source. See the [repository license](https://github.com/artifactshare/artifactshare/blob/main/LICENSE) for its terms, including the restriction on offering a directly competing hosted service.

You can follow the development of the web service, CLI, and documentation in the public repository. We will continue publishing fixes and improvements there.
