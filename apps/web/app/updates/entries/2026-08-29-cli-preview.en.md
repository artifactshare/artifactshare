You can now read the HTML or Markdown an agent wrote in your own browser before sharing it. Say "preview it with as" and the file is served locally, looking the way it will once published.

To ask for a change, select the element or the text and leave a comment on it. Submitting a batch hands those comments to the agent, which reports back on each one as it fixes them. The page reloads whenever the file is saved, so you see the result in place.

Until now this meant a round trip: look in the browser, then put what you noticed into words in the terminal. Pointing at the place you mean removes that step.

Comments are stored locally and survive closing the preview. Nothing is uploaded. Sharing happens only when you choose it from the page.
