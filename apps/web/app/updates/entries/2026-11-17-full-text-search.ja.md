タイトルに加えて、HTML ファイルと Markdown ファイルの本文も検索できるようになりました。静的サイト内の HTML・Markdown ページの本文も対象です。Web、MCP の `list_artifacts`、CLI の `artifacts list` から使え、所有者、プロジェクト、期間で結果を絞り込めます。

<!-- more -->

検索対象は現在の公開版です。PDF と動画はタイトルと説明文が対象で、PDF の本文や動画の音声は含みません。

アクセスが有効な自分のファイル、直接共有されたファイル、自分がワークスペースやプロジェクトの共有対象に含まれるファイルが見つかります。管理者権限だけで開けるファイルは出ません。アーカイブ済みプロジェクト内のファイルは、初期状態では検索対象から除かれます。

リンク共有だけでアクセスできるファイルは、ログインして一度開いたものに限られます。リンクの期限が切れておらず、停止されておらず、ワークスペースのリンク共有ポリシーで許可されている間だけ見つかります。自分が所有している場合や直接共有されている場合は、それぞれの条件で検索対象となるため、事前の閲覧は必要ありません。制限付きエージェントやボットの資格情報では、さらに読み取り可能なプロジェクトの範囲に絞られます。
