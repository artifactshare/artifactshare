---
title: Translate and print the body of shared files in Chrome
date: 2026-11-06
products: [web]
kind: new
notice: true
---

The "⋯" menu on share pages now has "Open body alone in a new tab". In that tab, Chrome page translation covers the body too. Use it when you share a file with someone who reads another language.

Until now, page translation on a share page only translated the header, because the body sits in a separate area of the page. The new tab shows the body alone, and the share page stays open as it was.

It also helps with printing long pages. A page that shows only its first page in Chrome's print preview from the share page shows in full from the new tab.

<!-- more -->

It works for HTML files, Markdown files and folder shares (static sites), and people who aren't signed in can use it from a shared link. The tab opens the version you're viewing, including past versions. For a folder share, it opens the entry page, whichever page you're viewing.

Comments aren't available in the new tab. Markdown diagrams (Mermaid) appear as code, and the code "Copy" button doesn't work. If you reload an HTML or Markdown tab, it won't open again. In a folder share opened while signed in, you can't move between pages after about 10 minutes. When that happens, go back to the share page and open it again.

People who aren't signed in don't see this menu item on files from recently created Free workspaces. Content in iframes inside a file may stay untranslated.
