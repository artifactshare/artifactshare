---
title: 共有ページの外部アプリリンクを開けるようにしました
date: 2026-07-27
products: [web]
kind: improve
---

共有ページに表示された HTML、Markdown、静的サイトの中から、`cursor:`、`vscode:`、`codex:`、`claude:`、`claude-cli:` のリンクを対応アプリで直接開けるようにしました。共有されたファイルから Cursor の MCP 設定や VS Code のファイルを開いたり、Codex・Claude・Claude Code でそのまま作業を始めたりできます。

外部アプリが自動で起動することはなく、閲覧者がページ内のリンクをクリックし、ブラウザの確認ダイアログで許可した場合にだけ開きます。共有ページに新しいボタンを追加する変更ではなく、ページに元からあるリンクが動くようになります。許可リストに含まれない URL スキームは引き続き遮断します。
