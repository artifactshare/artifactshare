title: See who viewed your files
date: 2026-08-19
products: [web]
kind: new
notice: true
---

On the shared page, "Who viewed" now includes signed-in people the file or project was shared with, alongside internal members. Open it from the viewer count next to the view counter, or from "Who viewed" in the "…" menu.

- External recipients with an explicit file or project share are included and can see other recipients of the same file. People who only have the link are not included.
- Viewing history from before this feature became available is also shown.
- Entries record that a file was opened; they are not read receipts.
