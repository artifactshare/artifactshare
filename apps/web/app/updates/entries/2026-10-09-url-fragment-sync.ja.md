---
title: スライドのページやダッシュボードの絞り込み状態を URL で共有できるようにしました
date: 2026-10-09
products: [web, agent]
kind: new
notice: true
---

スライドのページ番号やダッシュボードのタブ・絞り込み状態を、URL ごと相手へ渡せるようにしました。共有したファイルが状態を URL の `#`（フラグメント）に持っていれば、見ている状態が共有ページの URL にそのまま反映され、受け取った人も同じ状態から開けます。

たとえば `/a/<id>#/3` を開くとスライドは 3 枚目から始まり、ダッシュボードで期間や媒体を絞り込むと URL が `#from=2026-07-01&media=video` のように変わります。「共有リンクをコピー」でコピーされる URL にも、その時点の `#` が付きます。

<!-- more -->

HTML、Markdown、フォルダ共有（静的サイト）のどれでも使えます。Markdown では目次から見出しへ移動したときも URL に反映されます。ファイル側に Artifact Share 専用のコードは不要で、通常どおり `location.hash` や `history.replaceState` で `#` を読み書きするだけで連動します。

共有ページはブラウザ履歴を積まないため、「戻る」を押す回数が増えることはありません。ログインが必要なファイルでも、ログイン後に同じ状態のまま開きます。

連動するのは `#` だけで、クエリ（`?tab=`）やパスに状態を持つページは対象外です。フォルダ共有では入口のページを開いているあいだだけ URL を更新し、別ページへ移ると更新を止めます。CLI のローカルプレビューも対象外です。
