title: スライドのページやダッシュボードの絞り込みを、URL で共有できます

スライドのページ番号や、ダッシュボードのタブとフィルタを、URL ごと人に渡せるようになりました。共有したファイルが状態を URL の `#`（フラグメント）に持っていれば、いま見ている状態が共有ページの URL にそのまま反映されます。送られた人も、同じ状態で開けます。

たとえば `/a/<id>#/3` を開くと、スライドは 3 枚目から始まります。ダッシュボードで期間や媒体を絞り込むと、URL が `#from=2026-07-01&media=video` のように変わります。「共有リンクをコピー」でコピーされる URL にも、今の `#` が付きます。

<!-- more -->

HTML、Markdown、フォルダ共有（静的サイト）のどれでも使えます。Markdown では、目次から見出しに移ったときも URL に反映されます。ファイルの側に Artifact Share 専用のコードは要りません。いつもどおり `location.hash` を読み書きするか、`history.replaceState` で `#` を書き換えるだけです。

共有ページは履歴を積まないので、「戻る」を押す回数は増えません。サインインが必要なファイルでも、サインインしたあと同じ状態で開きます。

連動するのは `#` だけで、状態をクエリ（`?tab=`）やパスに持つページは対象外です。フォルダ共有では、入口のページを開いているあいだだけ URL を更新し、ほかのページに移ると止まります。CLI のローカルプレビューも対象外です。
