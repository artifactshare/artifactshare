Artifact Share CLI 0.11.0 で、AI エージェント向けのログイン設定を追加しました。`npm exec --yes --package=@artifactshare/cli -- artifactshare login --preset agent` を実行してブラウザでプロジェクトを 1 つ選ぶと、そのプロジェクトだけを扱える CLI セッションを作れます。

<!-- more -->

このセッションでは、共有されたファイルの閲覧に加え、エージェント自身が作ったファイルの投稿・更新と、閲覧できるファイルへのコメントが可能です。ファイルの削除や移動、共有範囲の変更、プロジェクトの管理は許可されず、権限はサーバー側でも検証されます。

新しいプロファイルで `--preset` を省略すると、従来どおりアカウントに許可された範囲をすべて扱えます。既存のプロファイルでログインし直したときは前回の設定を引き継ぐため、通常権限へ戻したい場合は `--preset unrestricted` を明示してください。用途ごとに分けたいときは `--profile <名前>` で別プロファイルを使います。

権限を絞ったプロファイルへ切り替えたら、不要になった古い資格情報も失効してください。ブラウザでログインした CLI セッションは `npm exec --yes --package=@artifactshare/cli -- artifactshare logout --profile <名前>` か「設定」→「トークン」から、API トークンは「設定」→「トークン」から失効できます。

構文とオプションの詳細は、[CLI コマンドリファレンス](/ja/guides/cli)をご覧ください。
