---
title: 共同作業者も同じ URL で新しいバージョンを追加できるようにしました

ファイルの所有者だけでなく、共同作業者も同じ URL で新しいバージョンを追加できるようになりました。ワークスペースまたはプロジェクトの共有範囲で閲覧できるメンバーが対象です。社外メンバーからの投稿が有効なワークスペースでは、メールアドレス指定で個別共有された相手も、Google または Microsoft でログインすれば新しいバージョンを追加できます。

ブラウザでは画面右下の「バージョンの状態」から、CLI ではこれまでどおり `artifactshare update` で新しいバージョンを追加できます。

<!-- more -->

共有リンクと所有者は変わりません。以前のバージョンは履歴に残り、各バージョンを誰が追加したかも確認できます。新しいバージョンを追加しても共有範囲の変更権限や所有権は移らず、共有を解除された社外の相手は閲覧も更新もできなくなります。

同じワークスペースのメンバーは、ワークスペースまたはプロジェクト共有のファイルについて名前変更やアクセス可能なプロジェクトへの移動も行えます（社外の相手が行えるのは新バージョンの追加のみです）。

プロジェクトに紐付けたエージェントも、そのプロジェクト内でプロジェクトまたはワークスペースに共有されているファイルへ新しいバージョンを追加できます。ホーム、個別共有、リンク共有、別のプロジェクトには更新範囲が広がりません。

複数人で同時に作業するときは、CLI の `--expected-version` で更新前のバージョンを指定できます。別の更新が先に反映されていた場合は上書きせず競合として止まります（エージェントからの更新では指定が必須です）。
