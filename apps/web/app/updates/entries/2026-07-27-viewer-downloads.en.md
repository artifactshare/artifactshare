---
title: Download files from pages displayed in Viewer
date: 2026-07-27
products: [web]
kind: improve
---

Files can now be downloaded from links and buttons in HTML or static sites displayed in Artifact Share Viewer. This fixes downloads such as data URI links using `<a download>` that the Viewer sandbox previously blocked. Authors can share a download page, and viewers can download its files using the controls already built into the page. This change does not add a new download button to Viewer.
