---
title: Home and file lists are easier to scan
date: 2026-08-04
products: [web]
kind: improve
---

We removed the global Recent activity section from Home to focus the page on Recently seen, My files, and Projects. Project-specific activity history remains available.

Unread comment counts now include only comments you can actually view, excluding inaccessible or deleted comments and hiding the count when it is zero. Opening an updated file clears its unread version-update indicator, while comments remain unread until they are shown in the comment panel. Returning to the list reflects each state correctly.

We fixed Home rows overflowing into the sidebar and removed hover previews only from the My files sidebar on Home, while retaining them in wider lists. Visibility chips now use the shorter labels Specific, Project, Company, and Link sharing. Permissions and recipients are unchanged.
