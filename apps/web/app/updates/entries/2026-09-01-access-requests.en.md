---
title: Request access to files you cannot open
date: 2026-09-01
products: [web, admin]
kind: new
notice: true
---

Opening a shared file without permission no longer leaves you at a dead end. Send an access request from that page. The request goes to someone who can approve it, such as the file owner.

<!-- more -->

The person reviewing the request receives an email. If the file's workspace is connected to Slack with permission to send notifications and that person's account is linked, they also receive a Slack message. When the requested file can be displayed, the notification opens it alongside the request so the reviewer can check the content before approving or rejecting it. If the file cannot be displayed, the notification still opens the request details for a decision. The approval screen shows who can view. Depending on the reviewer's permissions, they can share only the requested file or its project. Reviewers can also find pending requests from their profile icon in the upper-right.

Requesters no longer need to keep checking for a result. After a request is approved or rejected, they receive an email. If the file's workspace is connected to Slack with permission to send notifications and the requester's account is linked, they also receive the result in Slack. An approval notification opens the requested file directly.

Requests, decisions, and notification outcomes are recorded under Settings → Activity, where workspace owners and admins can review them later.
