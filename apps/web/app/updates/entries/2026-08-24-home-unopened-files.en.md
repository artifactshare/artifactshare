---
title: Find files you created before opening them
date: 2026-08-24
products: [web]
kind: improve
---

Home now shows files you created but have not opened yet above Recently seen. This includes files created through the web app, CLI, or an agent using your account.

Opening a file removes it from this section. It then appears in Recently seen, so both lists keep a clear purpose.

The same order is used on desktop and mobile. When more files are waiting, you can continue to the existing My files page.
