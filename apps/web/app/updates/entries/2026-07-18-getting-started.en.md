The Free plan on the pricing page now links to a new getting started page. No credit card is required, and you do not need a project for your first post.

<!-- more -->

The getting started page presents three ways to post: Web, CLI, and MCP. Web lets you upload from a browser. If you are signed out, you return to the upload page after signing in. If you are already signed in, the upload page opens directly.

CLI covers posting from an AI with shell access. MCP covers posting from chats in Claude, ChatGPT, and Cursor.
