---
title: Inventory view of all projects and files for Team admins
date: 2026-07-16
products: [admin]
kind: new
---

Team workspace admins can now review every project and file in the workspace from Settings, with metadata such as owner, who can view, and storage size.

<!-- more -->

Until now, admins could only see what was shared with them, so there was no way to check the workspace as a whole for files exposed through link sharing, or to find which projects and files were using the most storage.

The new Inventory page in Settings lists all projects ordered by storage size, and all files with owner, location, who can view, size, and last update. Files can be filtered by who can view — for example, only link-shared ones — and sorted by size.

The list shows metadata only. Opening a file still follows each person's sharing settings; admins who need to inspect contents transfer ownership first, as before.
